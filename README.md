# Seven Senses Explorer

A small, interactive website that introduces seven senses: sight, hearing, smell, taste, touch, balance, and body awareness.

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Explore

Choose a sense to try its demo:

- **Sight:** change the lighting and colors of a scene.
- **Hearing:** play tones at different pitches.
- **Smell:** view examples of familiar scents.
- **Taste:** explore common flavor examples.
- **Touch:** compare visual texture patterns.
- **Balance:** tilt a balance illustration.
- **Body awareness:** guide a dot into a target with the arrow buttons or keyboard.

Smell, taste, and touch demos are visual only; a screen cannot reproduce those sensations.

## Other pages

- `birthday.html` is a birthday greeting with a link to the surprise page.
- `surprise.html` contains a birthday GIF and a link back to the greeting.
- `aap.html`, `helloji.html`, and `hindusim.html` are additional HTML files in the project.

## Publish with GitHub Pages

Push the project to a GitHub repository, then go to **Settings → Pages**. Select **Deploy from a branch**, choose the `main` branch and `/(root)` folder, and save. GitHub will display the published site URL in the Pages settings.
